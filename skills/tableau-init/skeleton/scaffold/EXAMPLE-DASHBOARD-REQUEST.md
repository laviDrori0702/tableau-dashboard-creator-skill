# Dashboard Request — EXAMPLE

> **This is a demo example under `scaffold/`.** To use your own request, create
> **`DASHBOARD-REQUEST.md` at the project root** (copy this file, or just paste
> your request when you run `tableau-intake`). Skills always prefer the root
> production file over this example — the example only lets you trial the
> workflow end-to-end before you've written your own.
>
> Drop the stakeholder's request in plain language — no structure required.
> `tableau-intake` reads it (or pasted text) and turns it into a structured
> `PRD.md`. Write as much or as little as you have; intake fills the gaps.

## What you want

Describe the dashboard in your own words. Helpful things to mention if you know them:

- **Who is it for?** (e.g., "the VP of Sales", "the regional ops team")
- **What decisions should it support?** (e.g., "spot regions falling below target")
- **What numbers matter?** (the KPIs / metrics you care about)
- **What should it look like / how will it be used?** (charts, filters, on a big screen vs. a laptop)
- **Any must-haves or constraints?** (brand colors, conditional formatting, specific sort orders)

---

_Example of a perfectly good free-form request:_

> I need a regional sales dashboard for the VP of Sales. The main thing is revenue
> and profit vs. target by region, with the ability to drill into a region to see
> its top products and customers. Highlight any region that's below target in red.
> It'll be shown on a large meeting-room screen. Use our brand blue if you can.
