# View: default

## Tile layout

| tile | sheet / object | notes |
|------|----------------|-------|
| KPI row | four KPI cards | Pattern: kpi-card |
| Trend | chart-trend | full width |
| Region | actual + target | side by side |
| Category | chart-category | |
| Customers | table-customers | |
| Filters | flt-* cards | left/top bar |

## Sidebar

| block | control | notes |
|-------|---------|-------|
| Filters | Month / Region / Category | multi-select where planned |

## Sizing

- Canvas: 1366 × 768 (from plan Screen Size)
- Use **range sizing** with a sensible minimum height per row
- Tiled **percentage** containers only — **never floating**
